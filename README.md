# Evacuation Simulator Desktop — версия 0.2.0

Учебен desktop прототип за редактиране на многоетажни планове и демонстрационни сценарии.

## Ново във v0.2
- Управление на етажи: добавяне, преименуване, премахване (поне един етаж остава).
- Редактор за помещения и коридори чрез два клика; врати, изходи, стълбища, групи хора и опасни зони.
- Избиране на обекти, преместване, редактиране на свойства и изтриване.
- Данни за класна стая: ученици/хора и учители; ширина на проход/елемент.
- Запазване и отваряне на локален JSON проект през системните файлови диалози.
- Прикачване на PDF като външен референтен файл и отварянето му с програмата по подразбиране.
- SVG експорт, печат и базови статистики.

## Стартиране
Изисква Node.js LTS и интернет при първоначалната инсталация на зависимостите.

```bash
npm install
npm start
```

За Windows инсталатор:

```bash
npm run dist
```

Изходният инсталатор ще бъде в `dist/`.

## Ограничения на тази версия
- PDF се прикачва като външна референция, но не се визуализира като мащабируема подложка в редактора.
- Симулацията е опростена визуализация на текущия етаж; не изчислява реалистична пропускателна способност, дим, структурни повреди, достъпност, взаимодействия между етажите или реално време за евакуация.
- Избраните сценарии са учебни режими, а не валидиран физически модел. Особено режимът за защитно укриване не моделира действия на нападател.
- Широчините са записани като свойства, но още не участват в изчисляването на потока.

**Важно:** Програмата не е сертифициран инструмент за проектиране или одобряване на евакуационни планове. Реалните планове и процедури трябва да се изготвят/проверят от компетентни специалисти и да следват указанията на местните служби.
